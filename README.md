# mnist-digit-classifierr
This project is a machine learning model built using TensorFlow/Keras to recognize handwritten digits (0–9) using the MNIST dataset.

## Features
- Data preprocessing and normalization
- ANN model training
- 97%+ accuracy
- Digit prediction
- Model saving/loading

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Dataset
MNIST Handwritten Digits Dataset

## Accuracy
~97.6%
